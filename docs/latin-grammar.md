# Latin grammar and annotation conventions

## Learning sequence

The student workflow follows **SCAN → LABEL → LINK → TRANSLATE → CHECK**. Begin by locating verbs and clauses; identify each token's morphology; connect syntactic roles; construct natural English from those relationships; then verify agreement, tense, case, negation, conjunctions, and implied words.

## Annotation record

Keep token position and surface form alongside lemma, part of speech, morphology, syntactic role, and head position. Morphology and syntax are separate: an ending can support multiple morphological readings, while syntax and context help select an interpretation.

Use familiar introductory labels (nominative, genitive, dative, accusative, ablative; person, number, tense, mood, voice). Preserve competing readings and explain ambiguous forms instead of silently choosing one. Store reviewed translations separately from literal glosses and allow multiple accepted renderings.

## Accuracy policy

Parser output and model confidence are evidence for a reviewer, not proof of correctness. Explanations should refer to the specific word form and sentence context. Never expose unreviewed NLP output as the answer key for student exercises.
